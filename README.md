Rockbuster Stealth Analysis
Project Summary
Rockbuster Stealth LLC, historically recognized for its widespread brick-and-mortar video rental stores, is transitioning into the digital age with the launch of its own online streaming platform. By utilizing its existing film licenses, Rockbuster aims to stay competitive in a market dominated by services like Netflix and Amazon Prime. This project centers on leveraging data analytics to guide both the launch and long-term strategic planning of the streaming service.

Key Business Questions

What is the average rental duration across all films?

Which films generate the highest and lowest revenue?

How do sales figures vary by geographical region?

In which countries are Rockbuster’s customers located?

Where are the highest lifetime value customers based?

Which movie genres are the most profitable?

Tools & Technologies

pgAdmin4: Interface for managing PostgreSQL databases.

PostgreSQL: Relational database system used to store and analyze Rockbuster’s data.

Tableau Public: Platform used to create and publish interactive visualizations.

Data Overview
The dataset provides a detailed view of Rockbuster’s operations, including:

Film Inventory: Information on movies, their genres, and rental durations.

Customer Profiles: Demographic details and rental activity.

Payment Transactions: Revenue data and transaction history.

Visual Insights
Interactive dashboards and visualizations can be accessed via Tableau Public, offering deeper insights into trends, customer behavior, and revenue patterns.
